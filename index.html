Frequently asked questions

Does Kanbanero work offline?

Yes. Creating and editing boards does not require an internet connection.

Where are my boards stored?

In a folder you choose. Each board is a .yaml file. You can select .json instead in Settings → Storage.

Can I use it with Git and pull requests?

Yes. Board files can be committed to a Git repository and reviewed in diffs or pull requests.

Is there a subscription?

No. Kanbanero costs $8.99 as a one-time purchase on the Mac App Store. There are no in-app purchases.

What are the system requirements?

Kanbanero requires macOS 14.6 or later on a Mac with Apple Silicon.

Is there an iOS, Windows, or Linux version?

No. Kanbanero is available for macOS only. Board files can be opened in a text editor on other platforms.

Does Kanbanero track me or collect analytics?

No. Kanbanero does not collect analytics or track usage.

What keyboard shortcuts can I use?
  • ⌘ N: add a new task
  • ⌘ ↵: save task
  • ⌘ L: show / hide project list
  • ⌘ T: toggle dark / light theme
  • ⌘ O: set project folder
  • ⌘ ⇧ ?: info view
